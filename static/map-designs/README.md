# Map design previews

The two local PNG previews are rendered from OpenFreeMap Positron and Dark.
They show the same area near Berlin's Museum Island at zoom 14.8.
OpenFreeMap symbol layers are omitted in the small previews to avoid clipped
labels; the interactive map uses the complete original styles. The light
preview represents the Positron fallback for the primary light basemap.

Attribution is displayed once in the containing map's attribution control:
OpenFreeMap / © OpenMapTiles / Data from OpenStreetMap. It is shared with the
live layer and deduplicated by OpenLayers, keeping the previews free of text.
These previews must be displayed with that shared attribution.
Sources: https://openfreemap.org/ and https://www.openstreetmap.org/copyright.
